# ⭐ LifeHub

A personal productivity hub developed in Python.

## About

LifeHub is a personal organization system created to practice Python programming while applying software development concepts such as modularization, code reuse, data structures and clean project organization.

The project is being developed incrementally, with each module introducing new programming concepts learned throughout my studies.

## Features

### ✅ Available

#### 💵 Financial Control

- Register income
- Register expenses
- Automatic balance calculation
- Financial history
- Summary of income, expenses and current balance

#### 🎁 Wishlist

- Add new items
- View complete wishlist
- Remove items
- Mark items as purchased
- Track purchase status

#### 🧴 Skincare Management

- Add skincare products
- View registered products
- Remove products
- Track product status
- Mark products as finished

#### 🎯 Goals Management
- Add new goals
- View registered goals
- Define goal category and deadline
- Track goal progress
- Automatically update goal status
- Mark goals as completed when progress reaches 100%
